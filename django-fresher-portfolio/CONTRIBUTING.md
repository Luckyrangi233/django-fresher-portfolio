# Working on this project

1. Open an issue describing one user problem and observable acceptance criteria.
2. Create a focused branch such as `feature/ticket-search`.
3. Make a small change, add or update tests, and run `python manage.py test`.
4. Open a pull request with the problem, change, test evidence, and known limitation.
5. Do not commit `.env`, database files, real personal data, passwords, or API keys.

For solo learning, use this process to practice explaining incremental engineering work. No contribution is complete until the behavior is tested and documented.
